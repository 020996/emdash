# Glass UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Two independent Appearance switches: macOS see-through window (vibrancy) and clean_my_mobile-style glass on cards/buttons/tabs/menus, keeping every theme's colors.

**Architecture:** Two `InterfaceSettings` booleans. Renderer mirrors them to html classes `em-transparent` / `em-glass` (+ localStorage for pre-paint). Main toggles BrowserWindow vibrancy through the existing settings runtime port. Transparency = theme tokens re-expressed with alpha via `color-mix`; glass = vanilla-extract `selectors: { '.em-glass &': … }` on the shared recipes.

**Tech Stack:** Electron `BrowserWindow.setVibrancy`, CSS `color-mix`, vanilla-extract, zod settings, Vitest.

**Spec:** `docs/superpowers/specs/2026-10-28-glass-ui-design.md`

## Global Constraints

- Both default `false`; both off = zero visual change.
- Theme hues never change; alpha + glass edge only.
- Transparent window: macOS only; switch hidden elsewhere.
- Editor (`--monaco-bg`), terminal (`--xterm-bg`), chat (`--chat-bg`): 85% theme background.
- Glass recipe: `--foreground` tint gradient 7.5% → 4% → 2.5%, 1px border 13%, top highlight 20% → 0 at 42%; `backdrop-filter: blur(24px) saturate(1.4)` only on popups (menus, popovers, dialogs, tooltips).
- No blur on list rows.

## Review Focus

1. Custom-property cycles: `--x: color-mix(var(--x) …)` on one element is invalid → token goes unset (white/transparent UI). Alpha'd `--em-surface-*` must read a `--glass-src-*` copy captured on `html` and be redefined on `body`.
2. Pre-paint inline `html { background-color }` (index.html) must not be set when transparent, or the window stays opaque.
3. Monaco theme colors must carry alpha (`#rrggbbaa`) and be re-defined when the switch flips; xterm needs `allowTransparency` updated at runtime.
4. Turning transparency off must restore an opaque native background (`setVibrancy(null)` + `setBackgroundColor`).
5. macOS `nativeTheme.themeSource` follows theme polarity only while transparent; back to `'system'` when off.
